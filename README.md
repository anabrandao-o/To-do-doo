# To DO doo

Aplicação de lista de tarefas desenvolvida com React e JavaScript, focada em organização, prática de lógica e boas práticas de desenvolvimento front-end.

## ✨ Funcionalidades

* ✔️ Adicionar e visualizar tarefas
* ✔️ Marcar tarefas como concluídas
* 🔴 Identificação de tarefas atrasadas
* 🟡 Aviso de tarefas próximas do horário
* 💾 Persistência de dados com localStorage

## 🧠 Objetivo

Este projeto foi criado com foco em evolução como desenvolvedora front-end, aplicando conceitos como:

* Gerenciamento de estado com React
* Separação de responsabilidades
* Uso de funções reutilizáveis (utils)

## 🚀 Tecnologias

* React
* JavaScript
* Sass

## 📌 Status

Em desenvolvimento — novas funcionalidades e melhorias estão sendo implementadas continuamente.
